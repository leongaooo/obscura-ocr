# Security policy

Do not post real documents, OCR output, credentials or personal data in public issues. After GitHub publication, use the repository Security tab / private vulnerability reporting if enabled. Until a private channel is configured, do not send sensitive reports through public issues; request a private channel without including exploit data.

The service defaults to loopback and has no built-in authentication or TLS. OCR output includes original text. Temporary cleanup is best-effort after process crashes and is not secure erasure. Review deployment isolation and file-parser risks before accepting untrusted files.
