# 架构决策记录：项目名称与定位

## 状态

已确认。

## 决策

采用 **ObscuraOCR** 作为英文项目名称，中文名称为 **暗纹 OCR**。项目作为独立开源仓库，聚焦 OCR、版面理解、敏感字段识别、文档脱敏和结果审计。

项目通过功能模块和发展阶段描述演进，不把具体版本号写入品牌、目录或核心架构概念。

## 选择理由

- `OCR` 让技术入口清晰可见。
- `Obscura` 有隐私、隐藏信息和科技品牌联想。
- 名称不绑定发票、报销或单一行业。
- 名称可以覆盖本地工具、私有服务、规则包和模型适配器。

## 影响

- README、文档、示例和后续代码统一使用 ObscuraOCR。
- 不引入当前报销系统或其他业务系统的命名空间。
- 第三方 OCR、模型和规则包的许可证与来源单独维护。
