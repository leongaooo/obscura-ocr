# 文档支持范围

| 格式 | 当前能力 | 限制 |
| --- | --- | --- |
| PNG/JPEG | 文字与字段 | EXIF 规范化后坐标；过大图像缩放 |
| PDF | 逐页 OCR，支持扫描页 | 默认最多 10 页；跨页票据候选不拼接 |
| 公司材料 | 通用 OCR 文字 | 无营业执照专用解析器 |
| 中国票据 | 分类、号码、金额、日期、购销方等候选 | 需人工确认；不认证真伪 |
| DOCX/XLSX/PPTX/TIFF/TXT/HTML | 尚未支持 | 未来按格式分别实施 |

加密、损坏、空文件及超限输入被拒绝。手写、严重模糊、印章覆盖和特殊版式无准确率承诺。
