# 安全与隐私

## 威胁模型

- 恶意文件触发解析器、PDF 或 Office 依赖漏洞。
- 脱敏文件仍在文本层、批注、附件或元数据中残留。
- 临时文件、缓存、崩溃转储和日志泄露原文。
- 规则包或模型包被篡改，造成漏识别或过度遮盖。
- 多租户任务、对象路径或下载链接越权。
- 远程 OCR 把文件发送到未授权服务。

## 最低控制

- 限制文件大小、页数、解压深度和处理时长。
- 为模型、规则包、镜像和第三方依赖建立来源与完整性记录。
- 原始、临时和输出文件使用不同权限和生命周期。
- 日志禁止记录完整身份证号、账号、票据原文和密钥。
- 下载链接短时效、最小权限并绑定任务。
- 清理失败阻断任务完成状态并产生告警。
- 远程引擎必须显式配置、可审计并支持完全禁用。

ObscuraOCR 提供技术控制，不自动等同于法律合规、等保、隐私认证或行业准入。
