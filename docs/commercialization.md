# 商业化方案

## 判断

具备商业化潜力，但尚无付费需求、准确率、吞吐或 SLA 的市场验证。先用真实授权试点建立效果、部署成本和维护责任证据。

## 开源价值

核心文字识别、字段规则、证据结构、HTTP 接口、合成样例与评测公开，允许用户在自己的基础设施上部署和集成。

## 可收费交付

私有化安装、离线交付、行业规则适配、效果评测、性能调优、系统集成与长期支持。企业治理、权限与审计需要实际实现和验收后才可承诺。

## 边界

不隐藏安全修复、不回流未经授权客户资料、不把开源许可当成第三方模型的授权。依赖和模型许可见 [第三方声明](../THIRD_PARTY_NOTICES.md)。不承诺未经测量的准确率或合规认证。
