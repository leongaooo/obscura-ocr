# 脱敏策略

## 默认原则

- 默认不可逆。
- 先规划、后执行，允许人工复核。
- 页面、文本层、元数据和嵌入对象分别处理。
- 记录策略来源和结果校验，不记录不必要的敏感原文。
- 校验失败时不标记任务成功。

## 策略类型

| 策略 | 适用场景 | 要求 |
| --- | --- | --- |
| 纯色遮盖 | 高风险字段和对外发布 | 清理文本层和隐藏对象 |
| 模糊处理 | 保留版面轮廓 | 不用于密钥和账号 |
| 部分保留 | 保留末四位等提示 | 调用方显式选择 |
| 结构化替换 | 文本和结构化输出 | 保留字段类型和替换标识 |
| 匿名化映射 | 文件内保持引用一致 | 映射表独立加密 |
| 元数据清理 | 作者、批注、修订 | 不能替代页面脱敏 |

PDF 必须重新读取文本层；图片必须修改原始像素；Office 必须清理批注、修订、隐藏文字、属性和嵌入对象；二维码要检查编码内容。
