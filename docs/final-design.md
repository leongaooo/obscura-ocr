# ObscuraOCR 最终设计与交付范围

## 定位与开源意义

暗纹 OCR 是自由部署、轻量集成的 OCR 技术服务。开源的意义是让文字识别、票据字段提取、坐标证据和异常复核能力能够脱离业务系统复用，避免云端账户和私有接口绑定。

开源脱敏指发布物移除公司材料、真实发票、内部服务器地址、凭据和业务代码。自动打码不是本次识别服务的交付承诺。

## 当前功能架构

```mermaid
flowchart LR
  A[浏览器或 HTTP 客户端] --> B[上传限额与内容嗅探]
  B --> C[临时副本和 PDF 页数校验]
  C --> D[图片规范化 / PDFium 逐页渲染]
  D --> E[PaddleOCR]
  E --> F[原始文字与坐标]
  F --> G[分类和字段规则]
  G --> H[候选 / 证据 / 复核原因]
  F --> I[JSON 响应]
  H --> I
  I --> J[删除临时副本]
```

## 模块职责

- `config.py`：带边界的部署设置，统一 `OBSCURA_OCR_` 前缀。
- `upload.py`、`validation.py`：内容识别、大小限制、图片规范化及临时副本生命周期。
- `engines/`：可注入的 OCR 协议与真实 PaddleOCR 适配。
- `classification.py`、`extraction.py`：只使用本次文字证据的纯规则。
- `contracts/`：分类枚举和字段候选类型；不引用业务系统。
- `service.py`：同一次推理返回原始 tokens 与候选。
- `app.py`：就绪检查、并发限制、错误边界和静态测试工作台。
- `cli.py`：显式模型准备和本地服务入口。

## 公共接口

`POST /api/recognize` 只接收 multipart `file`。返回输入指纹、文字、页码、识别像素坐标、字段值与证据。不是任务队列，没有持久任务查询和回调。具体说明见 [集成](integration.md)。

## 数据边界

金额保留小数文本；零与未知分开。号码保留前导零；日期必须为合法日历值。冲突候选留空并标记复核。支出截图负号按当前规则转为金额绝对值，保留原文证据。多页 PDF 的文字正常返回，字段规则保守拒绝跨页拼票。所有结果由调用方人工确认，不承担真伪或财税判断。

## 部署与集成

本机 Python 为默认；CPU Compose 为可交付部署配方，目标容器环境需实测。模型先准备再运行，不在服务启动时自动下载。离线环境复制已准备的模型目录和镜像。没有数据库、企业账号或前端构建依赖，HTTP multipart 即可集成。

## 当前限制与未来扩展

本次仅 PNG/JPEG/PDF；不提供 Office、自动遮盖、NER、审计库、权限、GPU 镜像或持久任务。后续按 OCR 扩展、文档处理、脱敏规划、企业治理推进，见 [Roadmap](roadmap.md)。扩展设计文档均标记为规划，不能作为已实现能力宣传。

## 商业化判断

具备以私有化部署、行业适配、效果评测、性能调优和维护订阅收费的潜力。当前未证明付费需求、准确率或可用性 SLA。核心开放并保留标准接口；商业服务不隐藏安全修复。详见 [商业化](commercialization.md)。
